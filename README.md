# Radavod

[Русская версия](README.ru.md)

A private family tree site that a family runs on its own Cloudflare account. Radavod is the Belarusian word for a family tree.

Nothing to install yet: the project is at the planning stage. The first version will have the tree, people and their sources, sign-in by invitation, GEDCOM import and export, and a guide for running your own copy. The interface will be in Russian and English.

Deploying your own copy: [sign-in settings](docs/self-deploy.md).

This repository holds code and invented examples only. A family's data stays in that family's own installation.
