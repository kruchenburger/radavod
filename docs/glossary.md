# Glossary

One thing has one name. Interface texts use the Russian and the English word, code uses the English one.

| Russian             | English   | Meaning                                                                                | Not                                        |
| ------------------- | --------- | -------------------------------------------------------------------------------------- | ------------------------------------------ |
| человек             | person    | Someone in the tree, living or dead                                                    | персона, запись, node, individual          |
| союз                | union     | Two people as a couple: a marriage, a civil one, or unknown. The wedding is an event   | брак (one kind of a union), пара, family   |
| родство             | kinship   | How a child is tied to a parent: by blood, adoption, guardianship, or unknown          | связь, relation                            |
| ветвь               | branch    | A named and coloured part of the tree. A person has one main branch or none            | ветка, линия, group                        |
| событие             | event     | What happened to people: its kind, date, place and who took part                       | факт, fact                                 |
| место               | place     | Where something happened. Its name and affiliation change over time                    | локация, адрес, location                   |
| источник            | source    | Where a fact is known from. A relative's story is a source too                         | документ (one kind of a source), reference |
| степень уверенности | certainty | How well a fact is known: hypothesis, one source, confirmed, contradiction, unresolved | достоверность, confidence                  |
| хранитель           | keeper    | The member who invites, changes roles, imports and erases. There may be several        | админ, владелец, owner                     |
| редактор            | editor    | The member who edits the tree                                                          | модератор, contributor                     |
| читатель            | reader    | The member who reads the tree                                                          | гость, viewer                              |
| родословная         | pedigree  | The view of one person with ancestors and descendants; the tree is the whole family    | вокруг человека, family tree               |
| корзина             | trash     | Where a removed person waits to be returned or erased                                  | архив, bin                                 |
