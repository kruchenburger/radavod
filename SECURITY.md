# Security

## Report a problem

Report it privately: [Report a vulnerability](https://github.com/kruchenburger/radavod/security/advisories/new). Only the maintainers see the report. Issues and pull requests are public, so don't use them for this.

Report the same way if you find a real family's data in this repository, in its history or in a comment. Name the place and leave the data itself out of the report.

Say what an attacker can do, how to repeat it and in which version or commit. Use an installation of your own and invented people, never another family's site.

When the problem is fixed, we publish an advisory and name you in it, unless you'd rather not be named.

## Versions

There is no release yet, so fixes go to `main` only.

## What counts

- Reading or changing a family's data without the right to.
- Keeping access after it was revoked.
- Running code in a visitor's browser.
- Getting a family's data or a secret past the checks of this repository.

Each family runs Radavod on its own Cloudflare account and is responsible for the settings of that account. Report problems in Cloudflare itself to Cloudflare.
