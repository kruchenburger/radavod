# Radavod

[English](README.md)

Приватный сайт с семейным древом, который семья держит на своём аккаунте Cloudflare. Радавод по-белорусски значит «родословная».

Устанавливать пока нечего: проект на стадии плана. В первой версии будут древо, люди и источники, вход по приглашению, импорт и экспорт GEDCOM и гайд, как развернуть свою копию. Интерфейс на русском и английском.

В репозитории только код и вымышленные примеры. Данные семьи хранятся в её собственной установке.
